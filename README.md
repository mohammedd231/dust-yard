# Dust Yard

First-person multiplayer free-for-all in the browser: M4 rifle and combat knife, matchmaking, invite links, practice bots.

- **Hosting:** static site on Vercel (`index.html` + `models/`).
- **Multiplayer:** Supabase Realtime (broadcast + presence channels, no database tables).
- **3D:** Three.js r128 + GLTFLoader from CDN.

## Controls
WASD move · mouse aim · left click fire/slash · right click aim down sights · R reload · 1 knife · 2 rifle · Q / wheel swap · V quick knife · Shift sprint · C crouch · Space jump · Tab scoreboard · Esc pause / invite link.
