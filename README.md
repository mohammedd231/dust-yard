# Dust Yard

First-person multiplayer free-for-all in the browser: AK-74U and combat knife, matchmaking, invite links, practice bots.

- **Hosting:** static site on Vercel (`index.html` + `models/`).
- **Multiplayer:** Supabase Realtime (broadcast + presence channels, no database tables).
- **3D:** Three.js r128 + GLTFLoader from CDN.

## Controls
WASD move · mouse aim · E get in/out of the rowing boat (W paddle, A/D steer, S back-paddle) · left click fire/slash · right click aim down sights · R reload · T inspect · 1 knife · 2 rifle · 3 sniper (right click: scope; 3 rounds, bolt after each shot) · Q / wheel swap · V quick knife · Shift sprint · C crouch · Space jump · Tab scoreboard · Esc pause / invite link.
